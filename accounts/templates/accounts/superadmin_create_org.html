What happens next

  1. The organization is created and marked active.
  2. The admin user is created with role Organization Admin.
  3. The admin signs in at the same login page as you.
  4. They'll see only their organization's workspace.

Choosing a type

  • BnB — short-stay rentals and property management.
  • Tours — packages, guides, vehicles.
  • Restaurant — menu, orders, suppliers.
  • Laundry — services, pickups, deliveries.
  • Mixed — multiple businesses under one org.

Security

Use a strong password. Businesses have their own separate, isolated workspace — no cross-org data leaks.
